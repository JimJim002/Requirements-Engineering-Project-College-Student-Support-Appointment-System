# Week 9 - Processes & Scrum

## 1. User Stories & Acceptance Criteria
1. User Story 1: As a student, I want to be able to filter support services by the department, service type and staff member / student mentor, and to be able to view the available time slots for a selected date, so that I am able to find the correct support service I require without fearing of booking the wrong support service.
2. User Story 2: As a student, I want to be able to book an appointment that is available using a valid date and to receive confirmation, so that I am assured that my booking has been successfully made without any conflicts.
